# Mining Game

A small mining game built in plain HTML, CSS, and JavaScript.

## How to play

1. Open `index.html` in a browser.
2. Click `Mine Ore` to extract resources like coal, iron, gold, and diamonds.
3. Upgrade your drill, cart, and auto-miner to increase your output.
4. Rest to regain energy and sell your cargo to earn gold.

## Files

- `index.html` – game layout
- `style.css` – visual styling
- `script.js` – game logic and state

## Notes

The game saves progress in the browser using `localStorage`.

## Run locally

You can simply open `index.html` directly, or serve the folder with a local web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
